# Triage Labels

The engineering skills use five canonical triage roles. This repo currently uses the default label strings.

| Skill role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

If GitHub labels are renamed later, update the right-hand column before using `triage`, `to-issues`, or `to-prd`.
